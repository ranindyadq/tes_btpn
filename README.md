# Transaction Aggregator

Penyelesaian tes teknikal untuk membuat fungsi `aggregateTransactions`.

## Deskripsi
Fungsi `aggregateTransactions` menerima sekumpulan data transaksi, kemudian:
1. Mengelompokkan dan menghitung total transaksi untuk setiap `userId`.
2. Mengembalikan array baru yang diurutkan berdasarkan `totalAmount` dari yang terbesar hingga terkecil.
